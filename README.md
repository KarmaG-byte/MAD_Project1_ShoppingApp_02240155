# TshongLa

TshongLa is a Kotlin + Jetpack Compose marketplace prototype for Bhutanese handmade and local products. It brings products that are often scattered across social-media pages into one clean buyer-and-seller experience.

## Included in this version

- Home screen with search, categories, featured products and bottom navigation
- Explore screen with reusable product cards and category filters
- Product-detail screen with rating, seller information and cart action
- Cart with quantity controls and an order summary
- My Shop seller dashboard with inventory cards
- Add Product form with validation-friendly controls
- Warm Bhutan-inspired Material 3 theme and reusable Compose components

## Run in Android Studio

1. Clone or download this repository.
2. Open the repository folder in Android Studio.
3. Allow Gradle sync to finish.
4. Select an Android emulator or connected phone (Android 7.0/API 24 or newer).
5. Press **Run**.

The current product data is sample UI data and can later be replaced with Firebase or another backend.
